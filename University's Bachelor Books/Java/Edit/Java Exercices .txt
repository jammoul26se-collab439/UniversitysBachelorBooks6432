Example:
Design a class named Triangle to represent a 
triangle. The class contains:
■ Three double data fields named side1, side2, and side3 that specify the three sides of the triangle. 
■ A no-arg constructor that creates a default triangle. Use the value 1 for each of three sides.
■ A constructor that creates a triangle with the specified side1, side2, and side3.
■ A method named area( ) that returns the area of this triangle.
■ A method named perimeter( ) that returns the perimeter of this triangle.
Note that the perimeter is the sum of the three sides and the area is calculated using the below formula:
s= (side1 + side2 + side3) / 2
Area = radical( s(s-s1)(s-s2)(s-s3)

1. Draw the UML diagram for the class Triangle.

Triangle
side1: double
side2: double
side3: double
+ Triangle( )
+ Triangle(s1: double, s2: double, s3: double)
+ area( ) : double
+ perimeter( ) : double



2. Implement (Write the code for) the class Triangle. 
public class Triangle {
 double side1, side2, side3;
 public Triangle() { // No-Arg Constructor
 side1 = side2 = side3 = 1.0;
 }
 public Triangle(double s1, double s2, double s3) { // Constructor with parameters
 side1 = s1;
 side2 = s2;
 side3 = s3;
 }
 public double perimeter() {
 return side1 + side2 + side3;
 }
 public double area() {
 double s = (side1 + side2 + side3) / 2; // or double s = perimeter() / 2;
 return Math.sqrt(s * (s - side1) * (s - side2) * (s - side3));
 }
} // end class

3. Write an application (also known as a test program) that creates two Triangle objects - one using the no-
arg constructor and the other with side1 4, side2 5, and side3 6. Display the area and perimeter of each 
triangle.
public class Application {
 public static void main(String[] args) {
 
 Triangle triangle1 = new Triangle( );
 Triangle triangle2 = new Triangle(4,5,6);
 
 System.out.println("Triangle 1:");
 System.out.println("The area is " + triangle1.area());
 System.out.println("The perimeter is " + triangle1.perimeter());
 
 System.out.println("Triangle 2:");
 System.out.println("The area is " + triangle2.area());
 System.out.println("The perimeter is " + triangle2.perimeter());
 
 } // end main 
} // end Application
